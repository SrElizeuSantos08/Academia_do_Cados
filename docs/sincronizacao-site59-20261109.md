# Sincronização com a versão publicada 59

Esta integração incorpora o cadastro de aluno sem aprovação administrativa, mantendo a confirmação por e-mail, a troca obrigatória da senha temporária e as restrições dos perfis de gestão. Solicitações antigas pendentes são liberadas no próximo acesso autenticado elegível; matrículas revogadas não são restauradas automaticamente.

O player Vimeo recebe controle de tela cheia/horizontal, adaptação do layout à paisagem e alternativa ao bloqueio de tela cheia pelo navegador. Mantém os 14 vídeos, seus hashes de privacidade, a retomada e o progresso. A aula básica 01 usa o vídeo 1244243146/2ab050e76e.

Também são incorporadas as diferenças das páginas legais, acessibilidade, consentimento e navegação presentes no site. Os PDFs e comentários das perguntas já existentes na Branch-Arakaki são preservados.

O histórico de migrações D1, o arquivo de vídeo original e os documentos exclusivos do GitHub são preservados. As diferenças entre os históricos de migrações do site e do repositório não são aplicadas como substituição nem executadas no banco. Esta entrega não altera credenciais, schema ou provedor de produção.

Validação local: 33/33 arquivos de testes aprovados, TypeScript sem erros e build concluído. Deno e a instalação limpa das dependências são conferidos pelo workflow existente do GitHub Actions. A rotação em smartphone físico permanece dependente da compatibilidade do navegador e do bloqueio de orientação do aparelho.

A publicação do site já ocorreu na versão 59; enviar estes arquivos ao GitHub não constitui uma nova publicação do site.
